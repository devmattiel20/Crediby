                 🧠 App
          cardData + setCardData
              │           ▲
              │           │
         Props │           │ Evento
              ▼           │
         CreditCard    CardForm
              ▲           │
              │           │
       Muestra datos   Usuario escribe


En palabras:
App guarda los datos.
App pasa los datos a CreditCard.
El usuario escribe en CardForm.
CardForm informa a App que hubo un cambio.
App actualiza el estado.
React vuelve a renderizar los componentes necesarios.
CreditCard muestra los nuevos datos. ✨

💡 Esto se llama lifting state up: el estado vive en el ancestro común más cercano cuando varios componentes necesitan acceder a él.
